Ribbon draws parallel bands that twist along their length, shaded across each fold so they read as three-dimensional strips. By default the palette mirrors from ribbon to ribbon (`tileMode="mirror"`), so neighbours flow into each other.

`count` sets how many ribbons, `depth` how strongly each is shaded, and `angle` which way they run. `spin` slowly turns them.
