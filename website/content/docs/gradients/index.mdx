Every type is its own component with typed props, and every one is also available through [`Gradient`](/docs/components/gradient) by name. They share [colors](/docs/guides/colors), [composition](/docs/guides/composition) and [motion](/docs/guides/animation) props, and any of them can be a layer in a [stack](/docs/components/gradient-stack).

`AngularGradient` is the same as `ConicGradient` under the name some design tools use.
