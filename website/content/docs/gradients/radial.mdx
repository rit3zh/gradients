Color spreads outward from `center`. At `radius` 1 the last color reaches the corner farthest from the center, so the gradient always covers the view; smaller values leave the outer color to [`tileMode`](/docs/guides/colors#tile-modes).

`shape="ellipse"` stretches the rings to the view's proportions, which suits wide banners and tall screens.

## Motion

`flow` sends the rings outward, like ripples. With the default `clamp` it switches to `mirror` so the rings breathe in and out seamlessly; use `tileMode="repeat"` with a closed palette for rings that keep travelling.
