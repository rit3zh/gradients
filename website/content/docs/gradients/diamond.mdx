A diamond is a radial gradient measured with Manhattan distance, so its rings have straight edges and four points. By default (`shape="fit"`) it stretches to the view's proportions; `shape="square"` keeps the sides equal.

`angle` rotates the diamond, and `spin` keeps it turning. `flow` sends rings outward from the center, which reads beautifully with soft palettes.
