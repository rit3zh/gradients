Sky renders a physically inspired atmosphere: each color channel fades with altitude at its own rate, through a camera with a gentle fisheye. It takes no `colors`; choose a `preset`, then adjust.

## Custom atmospheres

`extinction` sets how far red, green and blue each carry up the sky. Higher values keep a channel longer, so ember's `[0.4, 0.06, 0.01]` holds red all the way up while blue fades almost at once. `tint` colors the incoming light, `horizon` tilts the camera up, and `fisheye` curves the edges.

```tsx
<SkyGradient preset="dusk" horizon={0.6} tint="#FFD6A5" />
```

Sky is static, which makes it a cheap, beautiful base for a [stack](/docs/components/gradient-stack): add an aurora on top for night, or a glow for the sun.
