Wave stacks four sine swells of different lengths and speeds, then colors the view by height against them: toward the top takes the start of the palette, toward the bottom the end. The result looks like layered water or dunes in motion.

`frequency` fits more swells across, `amplitude` makes them taller, and `angle` changes the direction they travel.

/>

`smoothness` eases the transition across each swell; lower values give sharper color bands.
